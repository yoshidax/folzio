# Folzio v1.6.0

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and
not notarized; see the README for how to open it the first time.

## Improvements

- Add folders to favorites from the file list, and choose whether to restore
  the favorites section's expanded or collapsed state on startup.
- Use consistent folder context menus in the directory tree and file list.
  Paste into a right-clicked folder, and copy or duplicate folders in the tree.
- After moving items to the Trash from the file list, the next item is selected
  when available.

# Folzio v1.6.0（日本語）

macOS 15 以降の Apple silicon Mac が必要です。アプリは ad hoc 署名で、Apple の
公証を受けていません。初回の開き方は README を参照してください。

## 改善

- ファイルリストからフォルダをお気に入りに追加できるようにしました。また、起動時に
  お気に入りの開閉状態を復元するかどうかを設定できます。
- ツリーとファイルリストのフォルダの右クリックメニューをそろえました。右クリックした
  フォルダへのペーストや、ツリーのフォルダのコピー・複製もできます。
- ファイルリストの項目をゴミ箱に入れた後、次の項目があれば選択されます。
