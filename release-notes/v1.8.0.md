# Folzio v1.8.0

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and
not notarized; see the README for how to open it the first time.

## New

- You can check for updates from Folzio → Check for Updates…. On the first
  launch, Folzio asks whether to check automatically. If you agree, it asks
  GitHub for the latest release when it starts, at most once a day, and tells
  you once about each new version. You can change this in Settings (⌘,) →
  Updates.
  The update check is the only network communication of the app. It sends no
  files or information about them. Download and install new versions from the
  Releases page.

# Folzio v1.8.0（日本語）

macOS 15 以降の Apple silicon Mac が必要です。アプリは ad hoc 署名で、Apple の
公証を受けていません。初回の開き方は README を参照してください。

## 新機能

- Folzio → アップデートを確認… から、更新を確認できるようになりました。初回の起動時に、
  自動で確認するかどうかを尋ねます。同意すると、起動時に GitHub へ最新のリリースを問い合わせ
  （1 日に 1 回まで）、新しいバージョンがあれば 1 度だけ知らせます。設定は
  設定（⌘,）→ アップデート で変更できます。
  更新の確認は、アプリが行う唯一のネットワーク通信です。ファイルやその情報は送りません。
  新しいバージョンのダウンロードとインストールは、Releases ページから行います。
