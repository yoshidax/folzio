# Folzio v1.9.0

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and
not notarized; see the README for how to open it the first time.

## New Features

- The search sheet now accepts several search roots. Add or remove rows (up to
  10) to search multiple folders at once. The sheet also shows that the search
  keyword supports wildcards.

## Improvements

- Searching a folder tree with tens of thousands of media files is much faster
  and puts less load on your Mac. Thumbnails for the first visible items appear
  sooner, and results are added as they are found. The current sort order is
  applied once when the search finishes.

# Folzio v1.9.0（日本語）

macOS 15 以降の Apple silicon Mac が必要です。アプリは ad hoc 署名で、Apple の
公証を受けていません。初回の開き方は README を参照してください。

## 新機能

- 検索のシートで、複数の検索起点を指定できるようになりました。行を追加・削除して
  （最大 10 行）、複数のフォルダをまとめて検索できます。検索キーワードがワイルドカードに
  対応していることも、シートで分かるようにしました。

## 改善

- 5 万件規模のメディアファイルがある階層の検索を速くし、Mac の負荷を下げました。
  最初に見える範囲のサムネイルが早く表示され、検索結果は見つかった順に追加されます。
  現在の並べ替えは、検索が終わったときに 1 回だけ適用します。
