# Folzio v1.0.1

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and
not notarized; see the README for how to open it the first time.

## Fixes

- Prevent a crash when duplicating a file or folder whose name ends in a very
  large number. Duplicate names now increment without overflowing an integer.

## Distribution

- Support both flat and `Contents/Resources` layouts of SwiftPM localization
  bundles when packaging the app, including with Swift 6.0.
- Build release candidates and distribution ZIPs with GitHub Actions. Each ZIP
  includes an arm64 app and is accompanied by SHA-256 checksums.

# Folzio v1.0.1（日本語）

macOS 15 以降の Apple silicon Mac が必要です。アプリは ad hoc 署名で、Apple の
公証を受けていません。初回の開き方は README を参照してください。

## 修正

- ファイル名・フォルダ名の末尾に非常に大きな連番がある場合、複製でクラッシュする
  問題を修正しました。整数の桁あふれを起こさずに連番を増やします。

## 配布

- Swift 6.0 を含め、SwiftPM の翻訳リソースがバンドル直下にある場合と
  `Contents/Resources` にある場合の両方でアプリを作成できるようにしました。
- GitHub Actions で確認用候補と配布用 ZIP をビルドするようにしました。各 ZIP は
  arm64 のアプリを含み、SHA-256 チェックサムを添付します。
