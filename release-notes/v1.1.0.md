# Folzio v1.1.0

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and
not notarized; see the README for how to open it the first time.

## New Features

- Drag and drop files with other apps. Drag items from Folzio to a folder in
  Finder or to an upload field in a web browser, and drop items from Finder on a
  folder in Folzio or on the file list's background. Whether items move or copy
  follows the same rules as in Finder; hold ⌥ to copy or ⌘ to move.
- Drop items on the file list's background, or on a file that is not a folder,
  to move them into the displayed folder. While search results or the contents
  of a zip file are shown, only folders accept drops.

## Improvements

- Renaming a file or folder no longer re-sorts the whole list. Only the renamed
  row moves, so renames stay fast even with 10,000 search results.

# Folzio v1.1.0（日本語）

macOS 15 以降の Apple silicon Mac が必要です。アプリは ad hoc 署名で、Apple の
公証を受けていません。初回の開き方は README を参照してください。

## 新機能

- 他のアプリとファイルをドラッグ＆ドロップで受け渡せるようにしました。Folzio の
  項目を Finder のフォルダや Web ブラウザのアップロード欄へドラッグでき、Finder の
  項目を Folzio のフォルダやファイルリストの背景へドロップできます。移動かコピーかは
  Finder と同じ規則で決まり、⌥ でコピー、⌘ で移動になります。
- ファイルリストの背景や、フォルダでないファイルの上へドロップすると、表示中の
  フォルダへ移動するようにしました。検索結果や zip の中を表示しているときは、
  フォルダの上にだけ落とせます。

## 改善

- ファイルやフォルダの名前を変えたとき、リスト全体を並べ直さず、名前の変わった行
  だけを移動するようにしました。検索結果が 10,000 件あっても名前の変更が速く
  終わります。
