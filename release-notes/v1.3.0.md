# Folzio v1.3.0

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and
not notarized; see the README for how to open it the first time.

## New Features

- Zoom image previews with the mouse wheel or trackpad pinch, and drag to move
  enlarged images. The previous scroll behavior remains available in settings.
- Choose an installed application to open a file from its context menu.

# Folzio v1.3.0（日本語）
