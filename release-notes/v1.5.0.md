# Folzio v1.5.0

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and
not notarized; see the README for how to open it the first time.

## Improvements

- Right-click an unselected item in the file list to act on that item without
  changing the selection. Right-clicking a selected item acts on the selection.
- Choose separately whether to show confirmation dialogs for copying, moving,
  renaming, removing favorites, and moving items to the Trash. The Trash setting
  also applies to folders in the directory tree.

# Folzio v1.5.0（日本語）

macOS 15 以降の Apple silicon Mac が必要です。アプリは ad hoc 署名で、Apple の
公証を受けていません。初回の開き方は README を参照してください。

## 改善

- ファイルリストで選択していない項目を右クリックすると、選択を変えずにその項目を
  操作できるようにしました。選択中の項目を右クリックした場合は、選択中の項目を操作します。
- コピー・移動・名前の変更・お気に入りから削除・ゴミ箱に入れる操作について、
  確認ダイアログの表示を個別に設定できるようにしました。ゴミ箱の設定は
  ディレクトリツリーのフォルダにも適用されます。
