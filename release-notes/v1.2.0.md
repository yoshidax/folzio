# Folzio v1.2.0

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and
not notarized; see the README for how to open it the first time.

## New Features

- Save images from a web browser or another app by dragging them into Folzio or
  pasting image data with ⌘V. You can cancel an ongoing transfer with ⌘.

## Improvements

- Start and stop a slideshow with the same toolbar button. The button also
  shows whether the slideshow is running.

# Folzio v1.2.0（日本語）

macOS 15 以降の Apple silicon Mac が必要です。アプリは ad hoc 署名で、Apple の
公証を受けていません。初回の開き方は README を参照してください。

## 新機能

- Web ブラウザなどの画像を Folzio にドラッグするか、画像データを ⌘V でペーストして
  保存できるようにしました。受け取り中は ⌘. で取り消せます。

## 改善

- ツールバーの同じボタンでスライドショーの開始と停止ができるようにしました。
  ボタンに実行状態も表示されます。
