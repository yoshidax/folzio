# Folzio v1.4.0

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and
not notarized; see the README for how to open it the first time.

## New Features

- Filter the current list by name as you type in the toolbar search field.
  This also works inside ZIP files and on search results. Press ⌘F to focus the
  field, or use the magnifying glass to search subfolders.
- If you customized the toolbar in an earlier version, add the Filter item
  from the toolbar customization screen to use the new field.

# Folzio v1.4.0（日本語）

macOS 15 以降の Apple silicon Mac が必要です。アプリは ad hoc 署名で、Apple の
公証を受けていません。初回の開き方は README を参照してください。

## 新機能

- ツールバーの検索欄に入力すると、表示中の一覧を名前で絞り込めるようにしました。
  ZIP の中や検索結果でも使えます。⌘F で検索欄に移動でき、虫眼鏡から
  サブフォルダを含む検索を開けます。
- 以前の版でツールバーをカスタマイズしていた場合は、カスタマイズ画面から
  「絞り込み」を追加すると新しい検索欄を使えます。
