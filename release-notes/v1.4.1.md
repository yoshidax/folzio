# Folzio v1.4.1

Requires macOS 15 or later on an Apple silicon Mac. The app is ad hoc signed and
not notarized; see the README for how to open it the first time.

## Website

- Folzio now has a website in English and Japanese:
  https://yoshidax.github.io/folzio/
  It introduces the app with screenshots and short videos, and explains how to
  download and open it. The README links to it.

## App

- There are no changes to the app in this release.
