## 表示言語

- 表示言語は英語と日本語に対応し、初期値は英語。
- 設定（⌘,）の「言語」で変更する。
  変更はすぐに反映され、次回起動時にも復元される。
- macOS が提供する画面の文言は、システム設定に従う。

## バージョンの確認

- アプリメニューの「Folzio について」を選ぶ。
  アプリのアイコン、バージョン、GitHub リポジトリへのリンクを表示する。
- ⌘W で閉じる。メインウインドウを閉じると一緒に閉じる。

## フォルダ移動とお気に入り

### ディレクトリツリー

- ツリーにはホームとマウント中のボリュームが出る。
- フォルダの行をダブルクリックすると開閉する。
- 開閉の三角は、サブフォルダがあるフォルダにだけ表示される
  （隠しフォルダ・パッケージは数えない）。
- ⌘クリック・Shift クリック・Shift+↑↓ で、複数のフォルダを選択できる。
  - ファイルリストには、最後にクリック（またはキーボードで移動）したフォルダの内容が出る。
  - 選択したフォルダは、まとめてドラッグで移動できる。Option でコピーになる。
- ⌘Delete、または右クリックの「ゴミ箱に入れる」で、フォルダをゴミ箱に入れる。
  - フォルダは中身ごと入れる。複数選択は、まとめて1回の操作になる。
  - 設定に関わらず、確認が必ず出る。確認には各フォルダの名前と絶対パスが出る。
  - ホーム・ボリュームの最上位・お気に入りを含む選択では使えない。
    親子のフォルダを同時に含む選択でも使えない。
  - 表示中のフォルダをゴミ箱に入れたときは、ファイルリストに親フォルダを表示する。

### お気に入り

- ツリー最上部の「お気に入り」に、よく使うフォルダを登録できる。
- 登録するには、ツリーの右クリックで「お気に入りに追加」を選ぶか、⌃⌘T を押す。
- 削除するには、項目の右クリックで「お気に入りから削除」を選ぶか、⌘Delete を押す。
  - 確認が出て、表示名と絶対パスを示す。
  - 実際のフォルダは変更しない。
  - 通常のフォルダでは、⌘Delete は「ゴミ箱に入れる」になる。
- 名前を変えるには、Return、右クリックの「名前を変更」、「編集 > 名前を変更」のいずれかを使う。
  - 行の中で編集する。Return で確定、Esc で取り消し。
  - 空にすると、元のフォルダ名に戻る。
  - 確認はなく、実際のフォルダの名前は変わらない。
- ⇧⌘F で「お気に入り」の見出しへ移動する。
- 登録は保存され、次回起動時に復元される。
  見つからないフォルダは淡色で残る。

### ファイルリストのフォルダ

- ファイルリストにはサブフォルダも出る（隠しフォルダ・パッケージを除く）。
- フォルダの行をダブルクリックするか ⌘↓ を押すと、そのフォルダの一覧へ移る。
- ⌘↑ または先頭行の `..` で、親フォルダへ戻る。
  - ホームとボリュームの最上位には `..` は出ず、⌘↑ も何もしない。
- 一覧の中で移動すると、ツリーの選択もそのフォルダに追従する。
  キーボードフォーカスはファイルリストのまま。
- フォルダも、ファイルと同じくコピー・名前変更・移動・ゴミ箱への移動ができる。

### アプリの外での変更

- アプリの外でのファイルの追加・削除・名前変更を、一覧に反映する（FSEvents を使う）。

## 一覧と表示の切り替え

### 表示形式と列

- リスト形式とサムネイル形式を切り替えられる。サムネイルサイズも変えられる。
- 列ヘッダーをクリックすると並べ替える。
  - ファイル名順では、昇順・降順ともフォルダをファイルより前にまとめる。
  - zip ファイルはファイルとして扱う。
- 列ヘッダーを右クリックすると、作成日・種類・サイズ・変更日の列を表示・非表示にできる。

### ツールバー

- ツールバーには、表示形式の切り替えボタンとサムネイルサイズのスライダーがある。
- 既定は非表示。⇧⌘T で切り替え、状態は次回起動時に復元される。
- カスタマイズするには、ツールバーを右クリックして「ツールバーをカスタマイズ…」を選ぶ。
  - ボタンのグループをドラッグで並び替える。戻る / 進む、サムネイル / リストなどのグループは、1つの単位で動く。
  - グループを外して戻したり、スペースを追加したり、表示モードを変えたりもできる。
  - 並び順と表示モードは、次回起動時に復元される。

### ペインの表示切り替え

- 表示は3ペイン・ファイルリストのみ・プレビューのみの3つ。
  ツリーは単独では隠せない。
- 次のどれでも切り替えられ、3つの入口は同じ状態を共有する。
  - 既定のツールバー左側の「ファイルリストのみ表示」「プレビューのみ表示」ボタン
  - ⌃⌘2 / ⌃⌘3
  - 「表示」メニューの同じ項目
- ツールバーが非表示でも、メニューとショートカットで切り替えられる。
- ペインを隠している間は、次のようになる。
  - プレビューのみ表示中は、矢印キーで隠れたファイルリストの選択を移せる
    （サムネイル形式は上下左右、リスト形式は上下）。
  - 一覧にメディアがないときは、プレビューに「表示するメディアファイルがありません」と出る。
  - 隠したペインへのフォーカス・お気に入り・検索などの操作は無効になる。
  - フルスクリーンはどちらの表示からも使え、解除すると元の表示に戻る。
- 動画は `<` / `>` で5秒戻す・送る。3ペイン表示でも使える。
- 表示状態は保存されず、起動のたびに3ペイン表示で始まる。

### 種類フィルタ

- 種類フィルタで、画像のみ・動画のみに一覧を絞り込める。
- ツールバーの「画像のみ表示」「動画のみ表示」ボタン、表示メニュー、
  ⇧⌘I / ⇧⌘M で切り替える。
- 片方だけオンなら、その種類だけを表示する。両方オン・両方オフなら、すべて表示する。
- 状態は保存されず、起動のたびに両方オフで始まる。
  起動中は、フォルダを移っても状態を保つ。

## 画像と動画のプレビュー

### 表示

- JPEG / PNG / GIF / WebP / MP4 / MOV を表示する。隠しファイルと非対応形式は一覧に出さない。
- 画像は縦横比を保ってペインに合わせる。
  - ペインより小さい画像は、はみ出さない範囲で最大まで拡大する。
  - フルスクリーンも同じ。
- アニメーション GIF とアニメーション WebP は、OS 標準の API で再生する。
  再生に対応していないときは、先頭フレームを表示する。
- 動画は再生・ループ・自動再生の設定に対応する。
  プレビューの動画にフォーカスがあるとき、Space で再生・一時停止する。

### クイックルックと既定のアプリ

- ファイルリストで Space を押すと、選択したメディアをクイックルックで確認できる。
  - 行・サムネイルの位置から拡大して開き、もう一度 Space で閉じる。
  - 複数選択では、まとめて表示する。
  - 表示中は、矢印キーで選択を移せる。
  - プレビューで再生中の動画は、表示中は一時停止する。
  - 名前の変更中・フルスクリーン中・スライドショー実行中・zip の中では使えない。
- メディアの行・サムネイルをダブルクリックすると、既定のアプリで開く。
  zip の中では何もしない。

### 拡大・縮小

- プレビュー画像は、次のどれでも拡大・縮小できる。
  - ツールバーの虫眼鏡の3ボタン「拡大」「表示領域に合わせる」「縮小」
  - 表示メニュー
  - ⌘+ / ⌘- / ⌘0（拡大は ⌘= でもできる）
- フィット表示を100%とし、25%〜800%を25%刻みで変える。
- 画像は中央を基準に拡大し、はみ出した部分は表示しない。
  スクロール・パン・ピンチ・倍率の数値表示はない。
- 3ペイン・プレビューのみ表示・フルスクリーンで使える。
- 動画・空のプレビュー・表示できない画像・ファイルリストのみ表示では無効。
- 別の画像に切り替える（スライドショーの自動送りを含む）か、
  履歴を移ると、100%に戻る。
- フルスクリーン・ウインドウやペインのサイズ変更では、倍率を保つ。
- 倍率は保存せず、履歴にも記録しない。
- VoiceOver では、現在の倍率を値として読み上げる。

### フルスクリーン

- 画像・動画（周りの余白を含む）をダブルクリックするか、⌃⌘F を押す。
- Esc で元に戻る。
- フルスクリーン中は、画面のどこをダブルクリックしても元の表示に戻る。
- 動画の再生コントロールと画像のスクロールバーの上では、ダブルクリックしても切り替わらない。

## スライドショー

### 開始と操作

- ⇧⌘S、表示メニューの「スライドショーを開始」、ツールバーの再生ボタンで始める。
- 設定した切り替え間隔で、対象のメディアを表示順に送る。
  - 繰り返しがオンなら、末尾から先頭へ戻る。
  - 繰り返しがオフなら、末尾のメディアから間隔が経った時点で終了する。
  - 動画は再生を続ける。
  - 1件だけなら、同じ対象を表示したまま期限だけをやり直す。
    繰り返しがオフなら、間隔の後に終了する。
- 開始時はプレビューのみ表示にする。
  終了時は、元のペイン・フォーカス・幅へ戻る。
- スライドショー中は、次の操作ができる。
  - 矢印キーで隠れた一覧を移動し、期限をやり直す。
  - Esc で終了する。
  - `/` で動画の再生・一時停止、`<` / `>` で5秒シークする。これらは期限を変えない。

### スライドショーの設定

- 設定ウインドウ（⌘,）の「スライドショー」で、次を変えられる。
  - 切り替え間隔: 1〜3600 の整数秒（既定3）
  - 「最後まで表示したら先頭から繰り返す」（既定オン）
  - 切り替え効果: なし／クロスフェード／スライド／ズーム（既定なし）
- 確定した変更は次の自動送りから反映し、再起動後も復元する。
- 繰り返しは、動画のループ再生とは独立。

### 切り替え効果

- 効果は約0.5秒で、自動送りのときだけ付く。
- 矢印キー・開始・終了・スライドショー以外の選択変更には付かない。
- macOS の「視差効果を減らす」がオンの間は、「スライド」「ズーム」を「クロスフェード」で表示する。
  保存値は変えない。

### 制限と履歴

- スライドショー中は、ペイン切り替え・履歴移動は無効。
- 次の場合は自動で終了する。
  - 閲覧先が置き換わった
  - 対象が0件になった
  - ウインドウを閉じた
- 開始時の選択とプレビュー切り替えは、履歴に記録しない。
- 実行中の表示形式・サイズ・フィルタ・並べ替えの変更だけを、通常の表示状態として記録する。

## ファイルの整理

### ファイル操作

- コピー・移動・複製・名前変更・ゴミ箱・ドラッグ＆ドロップ・クリップボード操作ができる。
  フォルダは中身ごと扱う。
- 名前が衝突したときは、「置き換える」「両方残す」「中止」から選ぶ。
- 操作前に確認ダイアログが出る。設定で省略できる。

### ドラッグ＆ドロップ

- ツリーのフォルダや、どちらの表示形式でも選択したファイル・フォルダを、
  ツリーまたはリスト（検索結果を含む）のフォルダへドラッグすると移動する。
- ドロップ時に ⌥ を押すとコピーになる。
- 利用可能なお気に入りも宛先にできる。
- 次の操作は受け付けない。
  - 親フォルダとその配下の項目を同時に含む選択
  - 同じ親への移動
  - 対象フォルダ自身やその配下への転送
- 同名の項目がある場合は、設定に関係なく衝突ダイアログが出る。
- コピー元そのものへコピーする場合は、「両方残す」か「中止」を選ぶ。「置き換える」は選べない。

### 新規フォルダ

- ⇧⌘N、「ファイル > 新規フォルダ」、
  またはツリーのフォルダやファイルリストの背景の右クリックメニューを使う。
- 「名称未設定フォルダ」を作り、その場で名前を付ける。確認はない。
- 作る場所は次のとおり。
  - ファイルリスト: 表示中のフォルダの中
  - ツリー: 選択中または右クリックしたフォルダの中
  - お気に入りの項目: 登録したフォルダの中
- zip の中・検索結果・「お気に入り」の見出し・見つからないお気に入りでは使えない。

### パス名のコピー

- 「パス名をコピー」で、選択した項目の絶対パスを文字列としてコピーする。
  ⌥⌘C、編集メニュー、右クリックメニューで使える。
- 対象は、リストの1件のファイル・フォルダ・zip ファイル、
  またはツリーのフォルダ（ホーム・ボリュームの最上位・お気に入りの項目を含む）。
- 複数選択・`..` の行・zip の中の項目・「お気に入り」の見出しでは使えない。

## zip の中の閲覧

### zip の中の表示

- 一覧の zip の行をダブルクリックするか ⌘↓ を押すと、中を表示する。
- ⌘↑ または先頭行の `..` で、元の階層に戻る。
  zip の最上位からは、zip を含むフォルダの一覧へ戻る。
- zip はツリーには出ない。
- zip の中のディレクトリをたどり、画像・動画をプレビューできる。
- zip の中は読み取り専用で、コピー・名前変更・ゴミ箱などの操作はできない。
  zip ファイル自体は、通常のファイルと同じに操作できる。
- zip の中の日本語のファイル名は、文字コード（UTF-8 / Shift_JIS など）を
  名前ごとに自動判定して表示する。
- zip の中の動画は、一時ファイルへ展開せずに再生する。
  zip から直接読み出す。

### zip ファイルの表示の切り替え

- ツールバーの「zipファイルを表示」ボタン、表示メニューの「zipファイルを表示」、⌃⌘Z で切り替える。
- 既定は非表示。設定は保存され、再起動で復元される。
- ボタンは、種類フィルタの右・表示形式の左に並ぶ。
- オフの間、zip ファイルの行は一覧・選択・ファイル操作・
  フルスクリーンの移動の対象にならない。
- 種類フィルタとは独立で、両方の条件を満たす行だけを表示する。
- zip の中を表示している間に切り替えても、中の一覧は変わらない。

## 名前の検索

### 検索の開始

- ⌘F、または「ファイル」メニューの「検索…」を選ぶ。
- モーダルで「検索キーワード」と「検索起点ディレクトリ」を入力する。
  - 起点の既定値は、ファイルリストに表示中のフォルダの絶対パス。
  - キーワードには、同じ起動中に前回検索したものが全選択で入る。
  - 起点は `/` か `~` で始まるパスにする。
  - 存在しない・フォルダでない（zip ファイルを含む）・読めないときは、
    モーダルに理由が出る。

### 検索起点フォルダの選択

- 起点欄の「選択…」は、macOS 標準のフォルダ選択パネルを開く。
- 1つのフォルダを選んで「選択」を押すと、起点欄だけが変わる。
  検索は「検索」を押すまで始まらない。
- キャンセル・検証失敗では、元の入力と理由を保ち、選び直せる。
- 標準パネルでは、次のようになる。
  - ファイル・zip・パッケージをフォルダとして選べない。
  - 複数選択・新規作成はない。
  - 隠し項目は標準どおり ⌘⇧. で表示でき、隠しフォルダも選べる。
- 直接入力の既存の検証規則は変わらない。
- キーボード操作は次のとおり。
  - Tab で、キーワード → 起点 → 選択… → キャンセル → 検索の順に移る。
  - Space で「選択…」を開く。
  - 標準パネル内の Return・Esc・階層移動は、OS 標準のとおり。
    そこでの Return・Esc は、パネルだけに作用する。
  - パネルを閉じると、「選択…」へフォーカスが戻る。
- GUI で選んだフォルダ名の末尾の空白は、起点欄を編集しない間はそのまま使う。
  直接編集すると、従来どおり前後の空白を除いて解釈する。

### 照合の規則

- `*`（0 文字以上）・`?`（1 文字）を含むキーワードは、名前全体と一致させる。
- 含まないキーワードは、名前（拡張子を含む）への部分一致。
- 大文字小文字と、濁点の合成・分解（NFC / NFD）の違いは区別しない。
- 全角・半角、ひらがな・カタカナは区別する。
- 起点以下のすべての階層の、対応メディアファイルとフォルダを対象にする。
- フォルダ名も名前全体で照合する。
  「.」を含む名前（`2024.10_trip`・`photos.jpg`）も、拡張子として扱わない。
- 次は対象にしない。
  - 隠しファイル・隠しフォルダ
  - パッケージの中
  - シンボリックリンクのフォルダ（リンク自身とその中）。ファイルへのシンボリックリンクは対象にする
  - zip の中
  - 検索の起点そのもの
- 検索を始めた時点で「zipファイルを表示」がオンなら、zip ファイルの名前も照合する。
  - zip の中は対象にしない。
  - 検索中に設定を切り替えると、次の検索から反映する。

### 検索結果

- 結果は、ファイルリストに1つの一覧として、ファイルとフォルダを混ぜて出る。
  - 見つかった順に、現在の並べ替えで加わる。
  - ファイル名順では、フォルダが先頭にまとまる。
  - 検索中も操作できる。
- リスト形式には「場所」列（起点からのフォルダ）が出る。
  並べ替えにも使える。
- サムネイル形式では、場所をツールチップで示す。
- 一覧の上部の検索バーには、次が出る。
  - ファイル・フォルダ・zip ファイルの合計の件数
  - 検索中は「検索中…」
  - 一致がなければ「該当する項目はありません」
- フォルダの行は、通常のフォルダと同じ行になる。
  - ダブルクリック・⌘↓・右クリックの「中を表示」で開ける。
  - 開くと検索結果の表示を終え、そのフォルダの一覧を表示する。
  - ⌘[（戻る）で、検索前に表示していたフォルダへ戻る。
  - フォルダの行を選ぶと、プレビューは空になる。
- 一致した zip ファイルは、通常の一覧と同じ行で出る。
  - ダブルクリック・⌘↓ で、zip の中の最上位を開ける。
  - コピー・名前の変更・移動・ゴミ箱もできる。

### 検索結果での操作

- 検索結果でも、プレビュー・コピー・複製・名前の変更・ゴミ箱・移動ができる。
- ペースト・移動ペースト・⌘↑ はできない。
- ゴミ箱に入れた・移動した・外部で消えた行は、中の結果ごと一覧から外れる。
- 名前を変えた行は、新しい名前で残る。
  - 中の結果も新しい場所になる。
  - 新しく現れたファイル・フォルダは加わらない。
  - フォルダの行の名前を変えた場合は、照合済みかどうかで、
    中の結果を引き継ぐか列挙し直すかが変わる。
- 検索結果の一覧から、検索結果のフォルダの祖先をゴミ箱に入れたり移動したりしても、
  検索結果の表示は続く。行は中の結果ごと外れる。
- 検索結果の表示を終えたときに検索前のフォルダがなければ、
  「フォルダが見つかりません」と出る。
- ツリーから祖先をゴミ箱に入れたときは、従来どおり親へ移る。

### 検索結果の表示を終える

- ツリーでフォルダを選ぶ（選択中の行のクリックを含む）か、ファイルリストで Esc を押す。
- 表示を終えると、検索中なら止まる。
- 検索の条件・結果・「場所」の並べ替えは保存しない。

## ショートカット一覧

### ショートカットの変更

- このガイドのキーは既定値。
- 設定（⌘,）の「ショートカット」タブで、メニューのコマンドのキーを変更できる。
  行の「記録」を押してから、新しいキーを押す。⌘・⌃・⌥ のいずれかを含める。
- 次は理由を示して受け付けないため、2 つのコマンドが同じキーを持つことはない。
  - ほかのコマンドが使っている組み合わせ
  - 矢印・Space・Return・Esc・Tab などの固定キー
  - ⌘Q・⌘W などのアプリ／システムのキー
- 「未設定にする」で、コマンドのキーを外せる。外したコマンドは「未設定」と表示され、キーを持たない。
- 2 つのコマンドのキーを入れ替えるときは、空いているキーを探さずに次の順で行う。
  1. 1 つ目を未設定にする。
  2. 2 つ目に、1 つ目の元のキーを記録する。
  3. 1 つ目に、2 つ目の元のキーを記録する。
- 「既定値に戻す」で 1 つのコマンドを、「すべて既定値に戻す」で全コマンドを既定値に戻せる。
- メニュー・ツールバーのツールチップ・ショートカット一覧（⌘/）には、現在のキーが表示される。
- ⌃Tab で「一般」と「ショートカット」のタブを切り替えられる。

## 設定の保存先

- 設定は `UserDefaults` に保存される。
- ショートカットの変更は、既定値と異なるコマンドだけを `shortcuts.overrides` に保存する。
- `.app` と `swift run` では保存先が異なる。

```bash
# .app の設定をリセット
defaults delete local.folzio.Folzio

# swift run の設定をリセット
defaults delete FolzioApp
```

## ファイルが見えないとき

- システム設定 → プライバシーとセキュリティ → ファイルとフォルダで、Folzio にアクセスを許可する。
- ターミナルから起動している場合は、ターミナルへの許可を確認する。
