Website Privacy Policy

Last updated: November 15, 2026

This policy covers this website (yoshidax.github.io/folzio), which yoshidax runs as a personal project. The Folzio app itself does not communicate over the network and sends no data anywhere.

Google Analytics

This website uses Google Analytics 4, provided by Google LLC, to learn how visitors find and use the site so that it can be improved. When you visit, your browser sends the following to Google:

  • The pages you view and the page you came from
  • Links you click, such as the download button, and how far you scroll
  • Information about your browser and device, such as the browser type, screen size, and language
  • An approximate location (country and city) that Google derives from your IP address. Google states that Google Analytics 4 does not log or store IP addresses.
  • An identifier stored in a first-party cookie, used to tell visits apart (not set for visitors in the EEA, the UK, and Switzerland)

The site shows no ads. Google signals and ad personalization are turned off, and user-level data is kept for 2 months. For visitors in the European Economic Area, the United Kingdom, and Switzerland, Google Analytics runs without cookies and sends only limited, cookieless measurements.

To learn how Google uses this data, see How Google uses information from sites or apps that use our services. To stop sending data to Google Analytics, install the Google Analytics Opt-out Browser Add-on, or block cookies or JavaScript for this site in your browser.

GitHub Pages

This website is hosted on GitHub Pages. According to GitHub, the IP address of every visitor is logged and stored for security purposes. See What is GitHub Pages? and the GitHub General Privacy Statement.

Changes

This policy may be updated when the website changes. The date at the top shows the latest update.
